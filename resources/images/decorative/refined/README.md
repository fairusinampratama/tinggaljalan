# Ornament artwork checkpoint

These candidate SVGs are deliberately **not imported into the page component**.
They replace raster-derived contours with editable curves and consistent strokes.
Review the artwork before switching the application to these assets.

- `orangutan-canopy.svg`: named groups for branch, body, raised arm/hand, head,
  cheek flanges, face and foreground foliage. The hanging pose follows the
  available route-detail reference; the drawing is an original simplification.
- `foliage-sumatra-java.svg`: a continuous stem with Jawa-inspired four-part
  Kawung geometry and Sumatra-inspired mangosteen floral forms.
- `regional-flow.svg`: organic connectors combine those floral motifs with
  stepped diamond geometry inspired by NTT weaving.
- `regional-mobile.svg`: compact four-part floral and stepped diamond motifs.
- `regional-band.svg`: a horizontal contour links the three motif families.

These are stylistic regional interpretations, not certified traditional designs.
All SVGs use `currentColor`, rounded strokes, local reusable symbols, and no
embedded raster pixels or external resources. Standard strokes are 1.15 viewBox
units, with finer leaf veins/facial detail at .65 units. Page opacity is applied
by the existing decorative component, not embedded into these assets.

Inspect full-contrast renders and intended display widths before integration.
The original homepage regional mockup is still needed for its exact composition
comparison. Page integration, browser screenshots, preview approval and production
approval are subsequent stages.
